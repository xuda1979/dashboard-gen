    或任意静态文件服务器，属于只读型内部工具页面。

────────────────────────────────────────────────────
四、主要功能
────────────────────────────────────────────────────

  1. 声明式页面模型（DSL）：支持 5 种页面布局（hero/grid/sidebar/
     section/landing）与 34 种组件（headline、paragraph、list、steps、
     button、link、card、stat、stat-list、toc、badge、divider、quote、
     code、callout、kv、grid、table、chart、image、details、tabs、
     checklist、footnote、timeline、def-list、stepper、sparkline、status、
     heatmap、progress、terminal、gauge、breadcrumbs），支持主题令牌
     （accent、radius 等）与深色模式。
  2. 单文件静态生成：输入 DSL → 输出自包含 HTML，内联 CSS 与 SVG 图表
     runtime，零 CDN、零外部依赖、可离线打开。
  3. 内置图表组件：line / bar / pie 三类 SVG 图表，基于内嵌数据于浏览器
     端本地绘制（自实现 SVG path/rect/polygon 构造），不依赖任何图表库。
  4. 多源数据绑定：内嵌数组/对象、CSV、JSON（data:）、构建期文件
     （file: data.csv|data.json）、运行期只读拉取（data.fetch / self://）。
  5. 命令行 CLI：dg new（模板脚手架）/ dg build（构建）/ dg watch
     （监听重建）/ dg serve（本地静态服务，内置目录穿越防护）。
  6. 无障碍与可部署性：自动生成 skip-link、main/nav 地标、语义化表格、
     图表 role="img" 与 aria-label、可访问性检查脚本；附 GitHub Pages
     Actions 工作流，一键部署。

────────────────────────────────────────────────────
五、主要创新点
────────────────────────────────────────────────────

  1. 声明式 → 单文件自包含：以纯声明 DSL（YAML/JSON）描述完整页面，
     产物为无任何外部依赖的单个 HTML 文件，可离线打开、可审计、易分发。
  2. 免图表库的本地 SVG 图表：图表由页内嵌入的轻量 Runtime 依据数据
     以 DOM/字符串方式构造 SVG，生成 40KB 级自包含页面，杜绝 CDN 依赖。
  3. 服务端数据预绑定：构建期把内嵌数据收集进 window.__DG_DATA__，
     并按与渲染同序的稳定 id 绑定到各图表宿元，保证数据定位零错位，
     支持多样数据源（内嵌/文件/CSV/JSON/运行时拉取）统一绑定。
  4. 只读安全的本地服务：dg serve 内置路径穿越与畸形编码校验，页面
     严格只读，适合特权内部环境（对比 LLM 建站的低可控性）。
  5. 开箱即用的可访问性与部署：自动 a11y 属性生成 + 独立校验脚本 +
     GitHub Pages 工作流，产出即为可发布资产。
